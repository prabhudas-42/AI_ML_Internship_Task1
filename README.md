# Student Performance Data Analysis Using Python

## Project Description
This project analyzes sample student marks in Maths, Science, and English using Python.

## Objectives
- Load and analyze a CSV dataset.
- Examine dataset structure and data types.
- Check missing values and duplicate records.
- Clean the data and calculate student average marks.
- Generate statistical insights and visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
A sample dataset containing student IDs, names, and marks in three subjects.

## Visualizations
1. Average marks by subject.
2. Distribution of student average marks.
3. Maths marks versus Science marks.

## Files
- `student_performance.csv`: Original sample dataset.
- `cleaned_student_performance.csv`: Cleaned data with average marks.
- `visualization1_average_marks.png`: Subject average bar chart.
- `visualization2_marks_distribution.png`: Histogram of student averages.
- `visualization3_maths_vs_science.png`: Maths vs Science scatter plot.

## Conclusion
This project demonstrates a basic data analysis workflow using Pandas and Matplotlib.
